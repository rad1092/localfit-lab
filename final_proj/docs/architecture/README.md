## 세 문서에 공통으로 적용한 사실

1. 브라우저의 Next.js 앱이 별도 프록시 없이 FastAPI `/api`를 직접 호출한다.
2. 실제 지도는 Kakao Maps JavaScript SDK를 사용한다. 설치되어 있지만 현재 `src`에서 쓰지 않는 Mapbox 패키지는 활성 스택으로 보지 않는다.
3. 입지 점수는 OpenAI가 계산하지 않는다. 상위 `datacorpus`의 Raw → Silver → Gold → 검증 흐름과 규칙 기반 WLC/MCDA 엔진이 점수를 만들고 SQLite에 게시한다.
4. AI 상세 리포트는 DB 점수·지표·근거를 묶은 뒤 OpenAI 구조화 출력을 받고, 결정론적 critic으로 금지 주장·숫자 불일치·인용 누락 등을 검사한다.
5. RAG는 임베딩/Vector DB가 아니라 로컬 문서를 어휘 기반으로 고르는 경량 검색이다.
6. 현재 제품 런타임은 로컬 SQLite, 로컬 리포트 파일, 로컬 관리자 작업 DB와 subprocess worker에 의존한다.
7. 저장소에는 AWS IaC, Docker, 운영 리버스 프록시, 도메인, TLS, 배포 워크플로가 없다. AWS·도메인은 현재 구조가 아니라 이후 결정해야 할 배포 구조다.

## 문서 갱신이 필요한 시점

- AWS 서비스와 배포 토폴로지가 결정되었을 때
- 운영 도메인·HTTPS·CORS·Kakao 허용 도메인이 설정되었을 때
- SQLite 또는 로컬 파일을 외부 저장소로 이전했을 때
- 백그라운드 작업을 별도 큐/워커로 분리했을 때
- 점수 엔진 버전이 release candidate에서 정식 버전으로 승격되었을 때
- 실제 챗봇/리포트 품질평가 저장 구조가 추가되었을 때
