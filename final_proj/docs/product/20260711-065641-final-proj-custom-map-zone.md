# final_proj 사용자 지정 지도 분석권 결정

- `final_proj` 지도는 `공식 상권`과 `사용자 지정 분석권`을 분리한다.
- 공식 상권은 기존 경계를 표시하고 단일 또는 복수 선택할 수 있게 한다.
- 사용자 지정 분석권은 원, 사각형, 자유 다각형을 지원한다. 삼각형은 자유 다각형의 세 점 선택으로 처리한다.
- 사용자가 그린 도형을 공식 상권으로 표현하거나 현재 상권코드 점수를 그대로 적용하지 않는다.
- 점포 및 시설은 좌표 기반 포함 판정, 인구 및 유동인구는 격자나 소지역 중첩 집계, 매출과 임대료는 원천 데이터 해상도에 따라 추정 또는 참고지표로 구분한다.
- 결과에는 `직접 집계`, `면적 비례 추정`, `지역 참고지표`처럼 계산 근거와 신뢰도를 명시한다.
- 사용자 지정 영역은 공식 상권 테이블과 분리해 별도 geometry, 계산 버전, 데이터 충족률을 저장한다.
- 구현 순서는 공식 상권 경계 및 복수 선택, 도형 그리기, 세부 원천데이터 재집계, 상세리포트와 챗봇 연동이다.
