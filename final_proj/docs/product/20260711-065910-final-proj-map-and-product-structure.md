# final_proj 지도 개편과 제품 구조 메모

- 지도 개편 시 메뉴 순서만 조정하지 않고 제품 정보구조와 백엔드 도메인도 함께 재검토한다.
- 현재의 `상권 분석`, `경쟁 분석`, `AI 리포트`, `마이페이지` 병렬 메뉴는 화면 구현 단위를 나열한 구조라서 재사용하지 않는다.
- 사용자 영역의 최상위 구조 후보는 `입지 탐색`, `분석 프로젝트`, `리포트`다.
- `입지 탐색`은 공식 상권 선택, 사용자 지정 분석권, 지도 데이터 레이어와 빠른 지표를 담당한다.
- `분석 프로젝트`는 위치, 업종, 예산, 후보지, 분석 스냅샷, 비정형 근거, 대화, 리포트를 하나의 검토 단위로 묶는다.
- 수요와 매출, 업종과 경쟁, 비용과 위험, 지역 이슈, 후보 비교는 독립 최상위 메뉴가 아니라 프로젝트 내부 분석 영역으로 둔다.
- AI는 메뉴 목적지가 아니라 분석, 대화, 리포트 전반에 적용되는 기능으로 취급한다.
- 입지봇은 현재 프로젝트와 선택 영역을 이해하는 전역 상담 도구로 둔다.
- 데이터 관리와 설정은 사용자 메뉴와 분리한 `운영 콘솔` 영역으로 둔다.
- 백엔드도 상권코드만을 중심으로 두지 않고 프로젝트, 분석 영역, 후보지, 근거 스냅샷, 대화, 리포트 간 관계를 지원하도록 재설계한다.
- 이 구조는 앞서 기록한 공식 상권과 사용자 지정 분석권 분리 원칙과 함께 지도 개편 단계에서 검토한다.
