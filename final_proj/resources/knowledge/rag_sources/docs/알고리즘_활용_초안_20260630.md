# 논문·자료 기반 알고리즘 활용 초안

작성일: 2026-06-30

## 1. 현재 엔진의 위치

현재 입지판단 엔진은 다음 구조다.

```text
원천 데이터
→ FeatureMart
→ 상권-업종-분기 행 선택
→ 지표별 백분위 변환
→ 7개 컴포넌트 점수
→ 업종별 가중합
→ JSON
→ AI 상세리포트 문장화
```

ML 예측값은 제품 경로에서 제외되었으므로, 앞으로 점수 근거는 알고리즘과 규칙으로 설명되어야 한다.

## 2. 현재 점수 축의 재정의 후보

현재 7개 축은 유지 가능하지만, 논문/자료 기반으로 아래처럼 더 명확히 재정의하는 것이 좋다.

| 현재 축 | 보강 이름 후보 | 근거 자료 | 보강 방향 |
|---|---|---|---|
| 수요 | 배후수요/소비잠재력 | 서울 상권분석 인구/소비, Huff/Gravity, 국내 매출 영향요인 논문 | 유동/상주/직장/생활인구/소비를 분리하고 업종별 시간대 가중치 추가 |
| 매출 | 매출체력/가격탄력 | 서울 추정매출, 국내 상권 매출 논문, 백테스트 | 동업종 내 매출 백분위, 점포당 매출, 객단가, 시간대 매출 분리 |
| 경쟁/상권환경 | 경쟁강도/집적효과 | SBDC 점포, Huff/MCI, 국내 창폐업 논문 | 경쟁을 단순 감점하지 않고 집적효과와 과밀효과로 분리 |
| 접근성/유입 | 접근성/흡인권 | GIS suitability, 2SFCA, 교통 승하차, 생활이동 | 역/정류장 개수보다 거리감쇠, OD 유입, 집객시설 거리로 강화 |
| 성장/안정성 | 지속성/변화위험 | 상권변화지표, 창폐업 논문, 서울신보 보고서 | 운영개월, 폐업개월, 변화지표, 매출 시계열 안정성 결합 |
| 예산/비용 리스크 | 비용압력/진입장벽 | 한국부동산원 임대료, 국토부 실거래, 공시/상업지 비용 자료 | 매매 프록시 한계를 명시하고 임대료 통계 확보 후 재가중 |
| 데이터 신뢰도 | 증거품질/메타데이터 신뢰도 | W3C DCAT/DQV/PROV-O, OECD, ISO, ESS, FCSM | 수집일, 기준기간, 공간단위, 결측, 계보, 직접성으로 정량화 |

## 3. 실제 추가할 수 있는 방법론

### 3.1 GIS-MCDA/WLC 기본 점수

현재 백분위+가중합은 GIS-MCDA의 WLC 방식으로 재정의할 수 있다.

```text
S_i = Σ w_j * x_ij
```

- `S_i`: 후보 상권-업종의 적합도
- `w_j`: 지표 또는 축 가중치
- `x_ij`: 0~1 또는 0~100으로 정규화된 지표 점수

보강해야 할 점:

- 지표별 정규화 방식을 문서화
- 편익형/비용형 방향을 명시
- 제약조건은 별도 mask 또는 penalty로 처리
- 민감도 분석을 함께 제공

### 3.2 AHP 또는 SMARTER 가중치

현재 가중치는 백테스트와 운영 판단이 섞여 있다. 앞으로는 두 층으로 분리하는 것이 좋다.

```text
전문가/사용자 가치 가중치: AHP 또는 SMARTER
데이터 기반 보정 가중치: 백테스트 신호
최종 운영 가중치: 두 값을 혼합
```

AHP 사용 시:

```text
A w = λmax w
CI = (λmax - n) / (n - 1)
CR = CI / RI
```

CR이 높으면 전문가 가중치를 그대로 쓰지 않고 재입력 또는 보정한다.

### 3.3 TOPSIS 후보지 순위

여러 후보지를 동시에 비교할 때는 현재 총점보다 TOPSIS가 설명력이 좋다.

```text
r_ij = x_ij / sqrt(Σ_i x_ij^2)
v_ij = w_j * r_ij
C_i = D_i^- / (D_i^+ + D_i^-)
```

- `D_i^+`: 이상적 최선점과의 거리
- `D_i^-`: 이상적 최악점과의 거리
- `C_i`: 상대적 근접도

활용:

- 후보지 A/B/C 비교
- 왜 1등인지 설명
- “한 지표만 높아서 총점이 높아진 문제” 완화

### 3.4 Huff-lite 흡인력 점수

거리와 경쟁을 실제 계산식으로 넣으려면 Huff 계열이 필요하다.

```text
P_ij = A_j^α * d_ij^-β / Σ_k A_k^α * d_ik^-β
```

- `P_ij`: 수요지 `i`가 상권/점포 `j`로 흡인될 확률
- `A_j`: 매력도, 예: 매출, 점포수, 집객시설, 브랜드/시설 proxy
- `d_ij`: 거리 또는 이동시간
- `α`, `β`: 매력도/거리감쇠 계수

초기에는 계수 보정이 어렵기 때문에 `Huff-lite`로 시작한다.

```text
매력도 = 매출백분위 * 0.4 + 집객시설백분위 * 0.2 + 점포집적백분위 * 0.2 + 유동인구백분위 * 0.2
거리 = 후보지 또는 상권 중심점 간 직선거리
```

주의:

- 실제 방문확률로 표현하면 안 된다.
- 초기에는 “거리감쇠 반영 흡인력 지수”라고 표현한다.
- 도보/대중교통 시간행렬을 확보하면 계수를 다시 보정한다.

### 3.5 2SFCA/E2SFCA 배후권 접근성

반경 기반 접근성과 공급/수요 균형을 설명하려면 2SFCA가 유용하다.

```text
R_j = S_j / Σ_i D_i
A_i = Σ_j R_j
```

Enhanced 2SFCA는 거리대별 가중치를 추가한다.

```text
R_j = S_j / Σ_i D_i W_ij
A_i = Σ_j R_j W_ij
```

활용:

- 특정 후보지 주변 공급 과밀 여부
- 수요 대비 점포 수
- 동일 반경 내 교통/시설 접근성

## 4. 전처리 구조 변경 제안

현재 `FeatureMart` 하나에 모든 값을 넣는 방식은 최종 점수 계산에는 편하지만, 알고리즘 강화에는 부족하다.

권장 구조:

```text
research/
datacorpus/
  raw_sources/
  standardized_tables/
  spatial_layers/
  algorithm_features/
  scoring_mart/
  reportfacts/
  judgement_outputs/
```

필수 원천 메타데이터:

- source_id
- source_name
- provider
- original_url
- collected_at
- reference_period
- update_cycle
- spatial_unit
- time_unit
- coordinate_system
- license
- file_hash
- row_count
- key_columns
- join_method
- missing_rate
- preprocessing_script

## 5. 우선 구현 순서

자료 수집 이후 실제 알고리즘 강화는 다음 순서가 가장 안전하다.

1. 데이터 신뢰도 점수 재설계
2. 원천 데이터 메타데이터 테이블 생성
3. 현재 백분위+가중합을 GIS-MCDA/WLC 명세로 재정의
4. TOPSIS 후보지 비교 모듈 추가
5. AHP/SMARTER 가중치 입력 또는 관리자 설정 구조 추가
6. 상권 폴리곤/점포 좌표/교통 좌표 기반 거리행렬 생성
7. Huff-lite 또는 E2SFCA 흡인력/배후권 점수 추가
8. 백테스트를 매출 규모형, 성장형, 안정형으로 분리

## 6. 리포트 표현 원칙

강화 후에도 다음 표현은 피해야 한다.

- 성공확률
- 개별 매장 매출 보장
- 월세/권리금까지 반영한 수익성 확정
- 실제 방문확률

대신 다음 표현을 사용한다.

- 공공데이터 기반 입지 적합도
- 동업종·동분기 상대 비교 점수
- 거리감쇠 반영 흡인력 지수
- 배후수요 대비 공급 과밀도
- 데이터 신뢰도와 현장 확인 필요 항목
