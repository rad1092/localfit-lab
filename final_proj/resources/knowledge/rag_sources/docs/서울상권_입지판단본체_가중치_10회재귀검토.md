중요한 결론은 다음과 같다.

- 현재 점수는 다음분기 매출 규모와 동업종 내 매출 상위권 선별에는 근거가 생겼다.
- 현재 점수는 성장률 높은 후보를 찾는 목적에는 약하다.
- 따라서 운영 목적은 "성장주 발굴"이 아니라 "매출 체력이 높은 상권-업종 후보 선별"로 제한한다.
- 점수 산정은 공공데이터 기반 백분위와 가중치만 사용하며, 별도 예측모델 값은 반영하지 않는다.

## 1. 목적

이 문서는 입지 판단 본체의 가중치를 왜 현재 값으로 정했는지 기록한다.

현재 가중치는 최종 통계 검증으로 확정된 학습 가중치가 아니다. 공공 데이터, 논문, 기존 FeatureMart 구조, 설명 가능성, 샘플 검증을 바탕으로 만든 1차 운영 가중치다. 이후 실제 사용자 피드백, 폐업/매출 후행 검증, 전문가 검토가 붙으면 다시 조정해야 한다.

## 2. 가중치 설계 원칙

- 매출 하나로 결론내지 않는다.
- 수요, 매출, 경쟁, 접근성을 핵심 4축으로 둔다.
- 성장/안정성은 보조하지만 무시하지 않는다.
- 예산은 중요하지만 현재 월세/권리금 원자료가 없어 낮은 가중치로 제한한다.
- 데이터 신뢰도는 독립 점수이면서 게이트로도 사용한다.
- 음식점, 서비스, 소매는 같은 방식으로 보되 가중치를 약간 다르게 둔다.

## 6. 가중치 사용상 주의

현재 가중치는 "설명 가능한 1차 운영 규칙"이다.

다음 데이터가 추가되면 재조정해야 한다.

- 실제 임대료, 보증금, 권리금
- 후보 점포 면적과 층수
- 업종별 창업비용
- 브랜드력 또는 메뉴/가격대
- 후보지 정확 좌표와 상권 폴리곤 point-in-polygon
- 실제 개업 후 매출 또는 폐업 후행 검증 데이터

## 7. 다음 재학습 또는 재검토 기준

가중치를 자동 또는 반자동으로 다시 조정할 때는 다음 기준을 쓴다.

| 기준 | 재검토 방식 |
|---|---|
| 실제 후행 매출 확보 | 컴포넌트별 상관, SHAP, 순위 안정성 확인 |
| 폐업/생존 라벨 확보 | 생존분석 또는 분류 모델로 위험축 재조정 |
| 월세/권리금 확보 | 예산/비용 리스크 가중치 상향 가능 |
| 사용자 선택 로그 확보 | 클릭/저장/다운로드 기준 learning-to-rank 검토 |
| 전문가 검토 확보 | AHP 방식으로 업종별 가중치 보정 |
