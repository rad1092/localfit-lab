## 1. 목적과 배경

현재 입지판단 엔진은 백분위 정규화 + 가중합(GIS-MCDA의 WLC) 구조이며, 백테스트는
시간축(분기별 Spearman·십분위)만 사용한다. 이 방식에는 두 가지 검증 공백이 있다.

1. **공간 자기상관 미반영** — 인접 상권끼리 값이 비슷해서, 무작위 분할 백테스트는
   예측력을 과대평가할 수 있다. → **공간 교차검증(spatial cross-validation)** 방법론 필요.
2. **가중치 안정성 미검증** — AHP/백테스트로 정한 가중치가 흔들릴 때 등급·순위가
   뒤집히는지(순위역전) 확인하는 절차가 없다. → **MCDA 가중치 민감도 분석** 방법론 필요.

이 두 공백을 메우기 위한 근거 자료를, **전체를 다운로드할 수 있고, 동료심사 저널·표준기구·정부·공식
리포지토리 출처이며, 2회 이상 검증을 통과한 자료만** 모으는 것이 이번 작업의 목표다.

> **2026-07-03 개정**: 초판에서 수집했던 arXiv 프리프린트 3건(공간CV 평가, 순위역전, 가중합 표본추출)과
> 저급 저널 1건(IJRBS AHP)을 **신뢰등급 미달**로 제거하고, 동료심사 자료(AGILE-GISS/Copernicus,
> Scientific Reports/Nature)로 대체했다. 현재 목록은 전부 동료심사/공식 출처다.

> 주의: 원천 데이터 수집(codex, `datacorpus/` 영역)은 이번 작업과 무관하며 건드리지 않았다.
> 이번 수집물은 전부 `research/methodology_validation_sources/` 아래에만 적재했다.

## 4. 검증 절차 (2회 이상, 서로 독립적인 방법)

각 파일은 **성격이 다른 2개 이상의 검증**을 통과해야 채택했다.

### 4.1 1차 검증 — 구조 무결성 (PDF 트레일러 수준)
- 매직바이트 `%PDF-` (헤더), `%%EOF` (정상 종료), `startxref` (교차참조표), 파일크기 확인.
- **결과: 최종 채택 7건 전부 PASS.** 깨진 스텁·비심사·저급저널 자료는 검증/신뢰등급 단계에서 제거.

### 4.2 2차 검증 — 내용 완전성 (두 갈래로 교차 확인)
- (a) **객체그래프 + SHA256**: stdlib로 페이지 객체·`/Font`·`stream` 존재 확인 후 SHA256 산출.
- (b) **권위 있는 텍스트 추출**: poppler `pdftotext` 로 전체 본문 추출 → **7건 모두 정상 추출**(2만~9.4만 자).
  본문 끝까지 추출된다는 것은 파일이 중간에 잘리지 않은 완전본임을 의미한다.
- blockCV·meyer가 (a)에서 페이지수 저집계된 원인은 **압축 객체스트림(/ObjStm)** 으로 확인, (b)에서 정상 텍스트가 나와 완전본 확정.

## 5. 엔진 적용 방향 (이 자료로 무엇을 할 수 있나)

### 5.1 공간 교차검증 → 백테스트 신뢰성 보강
- 현행 `scripts/backtest_location_judgement_scores.py` 는 시간 분할만 사용.
- S1·S2의 결론(무작위 CV는 과대평가)에 따라, **자치구/행정동 단위 공간 블록 CV**를 추가한다.
- S3·S4는 블록 크기 산정(자기상관 반경 기반)과 폴드 구성 절차의 구체 근거로 사용.
- 기대 효과: "Spearman 0.66"이 공간 블록 CV에서도 유지되는지 확인 → 주장 신뢰도 상승.

### 5.2 MCDA 가중치 민감도 → 가중치·등급컷 정당화
- M1: 가중치 ±10~20% 섭동(OAT), 시나리오 분석의 표준 절차 근거.
- M2: 공간 MCDA에서 가중치 변경이 적합도·순위에 미치는 영향 측정(직접 사례).
- M3: AHP 공간 MCDA 가중치 robustness 검증 → 등급컷(A/B/C/D) 경계 안정성 검증.
- 기대 효과: `서울상권_입지판단본체_가중치_10회재귀검토.md` 의 가중치가
  "흔들려도 결론이 유지된다"는 정량 근거 확보.

### 5.3 우선순위
1. (선구현 가능, 데이터 대기 불필요) M1·M2·M3 기반 가중치 민감도 스크립트 → 기존 FeatureMart로 즉시 가능.
2. (선구현 가능) S1~S4 기반 공간 블록 CV를 백테스트에 추가.
3. (codex 원천데이터 수집 완료 후) 좌표·거리 데이터 확보 시 Huff-lite/2SFCA와 함께 재검증.

## 6. 남은 보강 여지 (선택)

- **글로벌 민감도(Sobol/Saltelli)**: 현재 OAT·시나리오 수준. 축이 많아지면 Sobol 지수 자료 추가 검토.
- **Moran's I / 순열검정**: 공간 자기상관을 백테스트 전에 정량화하려면 별도 통계 근거 자료 1건 추가 가능.
- 위 둘은 **구현 검증 단계에서 실제로 필요해질 때** 같은 절차(동료심사 한정·2회 검증)로 수집하면 된다.
